Functional · minimal-dependency · Bun-native

Composable packages that snap together like Lego.

Atlas is an à la carte set of functional, minimal-dependency Bun/TypeScript packages. Pick what you need — config, database, HTTP server, auth, storage, AI — and compose them into your app. No framework lock-in. No classes. Just functions and immutable data flowing through pipes.

#server.ts · a user API in a few lines 
import { defineConfig, env } from "@atlas/config"
import { connect } from "@atlas/db"
import { serve, router, get, json } from "@atlas/server"
import { requireAuth, token } from "@atlas/auth"

const db = connect({ driver: "sqlite", path: "./app.db" })

serve({
  port: 3000,
  routes: [
    get("/me", pipeline(requireAuth({ secret }))(
      (c) => json(c, 200, { id: c.assigns.auth.id })
    )),
  ],
})
Features

A toolkit, not a framework.

Each package works on its own or with the others. Wrap Bun's native APIs, not a pile of external dependencies.

🧩

Composable

Each package works independently or with others. Snap them together — there's no all-or-nothing buy-in.

λ

Functional

No classes, immutable data, composition over inheritance. Pipes compose via pipeline(); halt() short-circuits.

🪶

Minimal deps

Wrap Bun's native APIs, not external packages. Most packages ship with zero runtime dependencies.

⚡

Bun-native

Idiomatic to Bun: Bun.serve, bun:sqlite, Bun.sql, Bun.redis, Bun.password — no dotenv, no Node shims.

🔓

No lock-in

Use what you need and combine it with anything else. Atlas never demands you adopt the whole stack.

🛠️

Pipe-based server

A Bun.serve router with a Plug-inspired pipe system — middleware that's just composed functions.

🗄️

Typed data layer

Query builder, schemas, changesets, and migrations across Postgres and SQLite, validated with zod.

🔐

Auth & security

Password hashing, JWT, sessions, OAuth 2.1 server, OIDC sign-in, CSP, rate limiting, TOTP, audit logs.

🧰

Templates & CLI

Scaffold with atlas init --template — minimal, api, edge, fullstack, admin, realtime, ai, and more.

Packages

Twenty packages. Pick the ones you need.

Import each @atlas/<pkg> directly. Map paths in tsconfig.json and Bun resolves them at runtime.

  • ✦@atlas/config — typed environment variables and config resolution.
  • ✦@atlas/db · migrate — query builder, schemas, changesets, and timestamped SQL migrations.
  • ✦@atlas/server · edge — pipe-based HTTP server, WebSocket/SSE, and a TLS-terminating reverse proxy.
  • ✦@atlas/auth · security · oauth · sso — sessions, OAuth 2.1 server, OIDC relying-party, TOTP, audit log.
  • ✦@atlas/storage · cache · email · request — S3 storage, Redis cache, email transport, HTTP client.
  • ✦@atlas/ui · admin · cli · mcp · ai — React/Mantine blocks, auto admin, CLI framework, MCP server, AI/RAG/agents.

Get started

Add Atlas as one Bun package.

Atlas isn't on npm. Install it directly from the repo, then map @atlas/<pkg> imports in your tsconfig paths.

terminal 
# 1. install Atlas as a single bun package from GitHub
bun add github:wess/atlas

# 2. map @atlas/<pkg> imports in tsconfig.json paths, e.g.
#   "@atlas/config": ["./node_modules/atlas/packages/config/index.ts"]
#   "@atlas/server": ["./node_modules/atlas/packages/server/index.ts"]

# 3. import and compose
# import { defineConfig, env } from "@atlas/config"
# import { serve, router, get, json } from "@atlas/server"

# 4. run with Bun — and bump Atlas anytime with
bun update atlas   # resolved commit is pinned in bun.lock
